# Resume Tailoring Standards & Engineering Archetypes

This document defines the technical rules, domain archetypes, and bullet construction standards used by the PursuitsHQ tailoring engine.

---

1. **LeapGenAI (Ashburn, VA)**:
   - Primary Product: **Seismic, a 360-degree healthcare application serving doctors and patients**.
   - Must be present in bullet 1 across all tailored variants.
2. **SmartRevIQ (Delaware, DE)**:

   - Must be present in bullet 1 across all tailored variants.

   - `React.js` is **explicitly listed** in all Full Stack, SWE, and Backend profiles to maximize ATS keyword scores.
   - `pgvector` is excluded from the technical skills block (featured only in project bullets).

## 2. Bullet Quality Formula

Every bullet point in the Experience and Projects sections must pass the automated quality gate:

$$\text{Bullet} = \text{Action Verb} + \text{Technical Task} + \text{Mechanism} + \text{Concrete Outcome} + \text{Metric}$$

### A. Approved Action Verbs
Bullets must begin with one of the following concrete verbs:
- `architected`, `automated`, `built`, `created`, `delivered`, `deployed`, `designed`, `developed`, `engineered`, `implemented`, `integrated`, `migrated`, `orchestrated`, `streamed`.
*(Forbidden: `worked on`, `responsible for`, `helped with`, `assisted with`).*

### B. Word Count Target
- **Strictly 18 to 32 words** per bullet point.
- Bullets under 18 words lack depth; bullets over 32 words cause 2-page LaTeX vertical overflow.

### C. Technical Mechanisms
Must include an explicit mechanism matching:
`\b(using|with|through|by|via|applying|behind|across|while|then|on|into|from)\b`

### D. Concrete Outcomes
Must articulate a clear engineering result matching:
`\b(improv\w*|reduc\w*|cut\w*|rais\w*|achiev\w*|enabl\w*|secur\w*|process\w*|sustain\w*|ground\w*|keep\w*|guarantee\w*|eliminat\w*|deliver\w*|embed\w*|return\w*|expos\w*|restor\w*|validat\w*|confirm\w*|surface\w*|expand\w*|served)\b`
